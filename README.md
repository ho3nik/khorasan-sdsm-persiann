# khorasan-sdsm-persiann

**Paper (PDF):** https://ho3nik.github.io/khorasan-sdsm-persiann/paper.pdf

SDSM-style statistical downscaling of daily rainfall, using either rain-gauge records or PERSIANN-CDR satellite cells as the local target (predictand). It accompanies the preprint:

> F. Nikzat and H. Nikzat. *PERSIANN-CDR satellite precipitation as an alternative predictand for SDSM downscaling of CanESM2 rainfall in Khorasan Razavi, Iran.* Preprint (analysis carried out in 2021).

## Read this first

This is a **2026 Python reimplementation** of the 2021 workflow. The original study was run in the SDSM software, with some helper scripts, and those scripts and project files were lost. This code was written from the paper's method description. **It did not produce the numbers in the paper, and it has not been run on the original data.** The station records are not public, so results from this code will differ from the paper.

## What it does

1. **Data preparation:** reads gauge CSVs and SDSM-format predictor files (NCEP/NCAR, CanESM2); downloads PERSIANN-CDR from NOAA NCEI, crops it to Khorasan Razavi, and picks well-spread cells.
2. **Predictor screening:** correlation and partial correlation with p-values, by season, against wet-day occurrence and fourth-root amounts.
3. **Downscaling model:** SDSM's conditional model. A linear regression gives the wet-day probability, and a second regression gives the fourth-root rainfall amount. Sub-models can be monthly, seasonal or annual, and an ensemble of stochastic series is generated, with variance inflation and bias correction.
4. **Evaluation:** mean, maximum and total monthly rainfall, dry- and wet-spell length, percentage of wet days and annual totals, each scored with r, R², RMSE and Nash–Sutcliffe efficiency (NSE).
5. **Scenarios:** change in mean annual rainfall under RCP2.6, RCP4.5 and RCP8.5.
6. **Maps:** inverse-distance-weighted maps of every score (the paper used QGIS).

## Quick start

```bash
pip install -r requirements.txt
python -m pytest -q          # 9 tests
python -m ksdsm demo         # synthetic data -> full pipeline -> demo_run/results/
```

The demo uses **synthetic** data generated by `ksdsm/synthetic.py`, so the code can be checked end to end without the real inputs. None of it is Khorasan data.

## With real data

See `data/README.md` for sources and file layouts, then:

```bash
python -m ksdsm persiann-download --years 1983 2005 --out data/persiann
python -m ksdsm persiann-cells --n 46
python -m ksdsm run examples/persiann.toml
python -m ksdsm run examples/stations.toml   # needs the gauge data
```

Outputs: `metrics.csv` (scores per site, stage and statistic), `changes.csv`, `predictors.csv`, `screening.csv`, and `maps/`.

## Differences from SDSM and caveats

- Parameters are fitted by ordinary least squares. With `tune_bias = true`, the bias factor is set automatically to match the observed mean wet-day amount; SDSM users tune it by hand.
- The PERSIANN-CDR downloader follows NCEI's documented directory layout but was not run against the live server while this repository was being prepared.
- Monthly statistics are scored over their 12 calendar-month values, so high scores partly reflect the seasonal cycle.
- In the GCM base period, CanESM2 years are not synchronised with observed years. A year-by-year comparison of annual totals therefore gives r ≈ 0 and negative NSE even for a perfect model, as the demo shows. Compare distributions instead.

## Layout

```
ksdsm/        io, persiann, screening, model, stats, metrics, maps, pipeline, synthetic, CLI
examples/     configs for the station and PERSIANN-CDR runs (2021 periods)

```
